# Document Assistant — Project Requirements

The project provides employees with a simple internal document question-answering assistant.

## Functional requirements
- Employees can upload PDF documents.
- Employees can ask questions about uploaded documents.
- The assistant should answer using the available document content.
- Answers should reference the document used.

## Constraints
- The initial project supports PDF files of up to 10 MB.
- If relevant information is unavailable, the assistant must acknowledge it.
- Authentication is a planned future enhancement, not part of the initial release.
